# M10 第2次整合性監査・品質基盤強化

## 目的

初回リファクタリング後のプロジェクトを再監査し、本番CSP、PDF表示、保存JSON境界、テスト実効性に残っていた不整合を解消する。

## スコープ

- CSP下の公開マニュアル、PWAオフラインキャッシュ、PDF新規タブ表示の修正。
- 保存JSONの包含フラグと写真実サイズの安全な検証。
- テストコード型検査、カバレッジ、配備成果物検査、Chromium E2Eの追加。
- 互換範囲内の開発依存更新と監査文書の同期。

## 非スコープ

- ProjectFileスキーマVersion 1の変更。
- TypeScript 7等のメジャーアップグレード。
- `App.css` 全体の分割と写真Canvas処理の詳細なブラウザモック。
- Firefox、WebKitによるE2E。

## セキュリティに関する注記

- マニュアルJavaScriptは外部ファイル化し、CSPへ `unsafe-inline` を追加しない。
- 一般応募または包含フラグ無効時の機微情報・写真は、読込時にも状態へ取り込まない。
- CSPでオブジェクト、外部フレーム、基底URL変更、外部フォーム送信を禁止し、PDF用Blobフレームだけを許可する。

## 受け入れ条件

- 本番相当CSP下でマニュアルとPDF表示が動作する。
- マニュアル全章がPWAにプリキャッシュされ、オフラインで移動できる。
- 不整合な保存JSONから写真や配慮事項が意図せず復元されない。
- テストコードのTypeScript検査とカバレッジ閾値を満たす。
- Chromiumでデスクトップ、390px幅、A4/A3、PDFポップアップ、マニュアルを自動検証できる。

## テストシナリオ

- `npm run typecheck:test` で本番コードとテストコードの型を検査する。
- `npm run test:coverage` でlines/statements/functions 70%以上、branches 60%以上を確認する。
- `npm run check:deploy` でCSP、インラインスクリプト禁止、配備ファイル、Service Workerを検査する。
- `npm run test:e2e` で本番相当ヘッダー下の5シナリオをChromium実行する。
- `npm run check` で全検証を一括実行する。

## ロールバック時の注記

- マニュアル外部スクリプトとCSPは一体で戻し、`unsafe-inline` による回避は行わない。
- PDFタブの事前作成を戻す場合は、ポップアップ許可切れの回帰を受け入れない。
- JSON読込の安全側正規化を戻しても、保存スキーマ自体の変換は不要。
- Playwrightを外す場合も、単体テスト型検査、カバレッジ、配備検査は維持する。
