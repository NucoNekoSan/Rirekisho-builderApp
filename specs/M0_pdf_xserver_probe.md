# M0 PDF・Xサーバー検証

## 目的

アプリがサーバー側の個人情報処理なしに、静的ブラウザSPAとして動作し、PDFを作成できることを検証する。

## スコープ

- React/Viteによる静的SPAのビルドとXserver配備。
- ブラウザ内PDF生成、PWAキャッシュ、オフライン起動、更新通知。
- `.htaccess` によるSPAフォールバックとセキュリティヘッダー。

## 非スコープ

- サーバー側レンダリング、API、データベース、個人情報のサーバー保存。
- ネイティブアプリとしての配布。

## セキュリティに関する注記

- 履歴書データと生成PDFはブラウザ内で処理し、配備先サーバーへ送信しない。
- PWAキャッシュには静的アセットだけを保存し、入力内容を保存しない。

## 受け入れ条件

- `npm run build` が成功する。
- `dist/` を静的ファイルとしてアップロードできる。
- ブラウザ内でプレビューをPDFに変換できる。
- Xサーバーのフォールバック設定が `.htaccess` で対応されている。
- PWAとして動作し、オフラインでも操作できる（郵便番号検索を除く）。
- アプリ更新時にリロードプロンプトを表示する。

## テストシナリオ

- ビルドの検証。
- PDF表示/ダウンロードの手動検証。
- オフライン状態での操作の手動確認。

## ロールバック時の注記

- PWAを無効化する場合も、通常の静的SPAとPDF生成は維持する。
- `.htaccess` を戻す場合は、SPAフォールバックとセキュリティヘッダーを別途維持する。
