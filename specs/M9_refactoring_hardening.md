# M9 リファクタリング・保守性強化

## 目的

既存のユーザー向け動作と保存データ形式を維持したまま、責務の集中、重複実装、未命名の制約値、テスト不足を解消し、今後の修正時に回帰を起こしにくい構成へ整理する。

## スコープ

- `App.tsx` からフォーム部品、編集行、データ更新処理を分離する。
- PDFページ分割とA4/A3用データ準備の重複を共通化する。
- 入力制約、保存ファイル制約、印刷レイアウト値、エラーメッセージを名前付き定数へ整理する。
- 共通データ構造、Blobダウンロード、写真データ生成、配慮事項抽出の重複を解消する。
- デッドコード、デッドCSS、冗長条件、不要な公開宣言を削除する。
- 純粋関数とキーボードナビゲーションの自動テストを追加する。
- 要件、技術資料、Specs、利用者マニュアルを現行実装へ同期し、文書間の整合性検査を自動化する。

## 非スコープ

- 入力項目、PDF記載内容、JSONプロジェクトファイルのスキーマは変更しない。
- UIデザイン、配色、操作フローは、A3横履歴書のグレー背景削除を除いて変更しない。
- `App.css` 全体のファイル分割は、PDFの基準画像を準備した後の別作業とする。
- Canvas APIに依存する写真加工処理のブラウザモックテストは別作業とする。

## 変更内容

### アプリケーション構成

- `FormSection`、`TextField`、`TextArea`、`SelectField`、文字揃えUI、配慮事項入力部品を `components/FormFields.tsx` へ抽出した。
- 学歴・職歴および免許・資格の編集行を `components/EditableRows.tsx` へ抽出した。
- コア状態、基本情報の検証、行の追加・削除・移動、文字揃え更新を `hooks/useResumeEditor.ts` へ抽出した。
- 常に全セクションを返していた `visibleSections` と7つの常時真ガードを削除した。
- 読込、全消去、デモ適用時の一時UI状態リセットを共通化した。

### PDF・ファイル処理

- 履歴書と配慮事項シートで重複していたページ生成、残容量計算、セクション追加を共通ページビルダーへ統合した。
- A4縦とA3横で重複していた履歴分割、資格セクション、志望動機・自己PR・本人希望セクションの準備を共通化した。
- PDF側の文字揃え取得を `lib/alignment.ts` に統一した。
- テキストファイルとPDFのBlobダウンロード処理を共通化した。
- 写真読込経路で重複していた `PhotoData` 生成処理を共通化した。

### 型・制約・データ処理

- 同一構造だった `HistoryEntry` と `QualificationEntry` の基底を `DatedEntry` に統合した。
- 印刷分割、郵便番号、電話番号、文字揃え保存上限、写真寸法上限のマジック値を名前付き定数へ変更した。
- 郵便番号、電話番号、住所検索の重複エラーメッセージを定数化した。
- 配慮事項の機微項目抽出を定義配列ベースへ変更した。
- 機微情報の有無判定で、印刷フィールド全体を再生成しないようにした。

### CSS・保守設定

- `--resume-header-bg` の循環参照を実際の背景色へ修正した。
- A3横履歴書のスコープ内では `--resume-header-bg` を透明に上書きし、グレー背景を削除した。
- 未使用の `.resume-text-grid` と、スタイル定義を持たない `.textarea-field` の参照を削除した。
- `body` の重複した `margin: 0` を `index.css` へ一本化した。
- `.gitignore` に `coverage/` と汎用 `*.log` を追加した。

### テスト

- `alignment.test.ts` を追加し、既定値、非破壊更新、接頭辞削除を検証する。
- `textNormalize.test.ts` を追加し、NFKC正規化と数字抽出を検証する。
- `validation.test.ts` を追加し、レコード判定を検証する。
- `useGridKeyboardNav.test.tsx` を追加し、Enter・矢印移動と対象外操作を検証する。

### 文書整合性

- 要件、技術仕様、ロードマップ、テスト戦略、UI/UX設計をA4/A3対応と現行実装へ同期した。
- `docs/manual/draft/` を利用者マニュアルの正本とし、PWA説明、写真上限、履歴行数、資格空行数、A3の収容案内を訂正して `public/manual/` へ同期した。
- M0〜M8へスコープ、非スコープ、セキュリティ、ロールバックを補い、M9と同じSpecs形式へ統一した。
- `scripts/check-doc-consistency.mjs` を追加し、Markdownリンク、マニュアル同期、Specs必須見出し、索引、ロードマップを検査する `npm run check:docs` を提供した。

## セキュリティに関する注記

- サーバー保存を追加しない。
- 郵便番号検索で外部へ送る情報は郵便番号だけとする既存境界を維持する。
- 一般応募の保存データとPDFへ配慮事項を含めない既存境界を維持する。
- 写真をJSONへ含めるかどうかは、従来どおり利用者の明示選択に従う。

## 受け入れ条件

- `App.tsx` がフォーム部品と編集ロジックを直接定義しない。
- A4/A3のPDF構造、配慮事項のページ分割、JSON保存・読込が既存テストを通過する。
- A3横履歴書からグレー背景が除去され、A4縦と配慮事項シートには影響しない。
- キーボードナビゲーション、入力整形、文字揃え、行操作が変更前と同じ動作をする。
- `npm run test`、`npm run lint`、`npm run build` が成功する。
- `npm run check:docs` が成功し、正本と公開マニュアルおよびM0〜M9の文書構造が一致する。
- `npm run check` でlint、テスト、ビルド、文書検査を一括実行できる。
- M9完了時の基準として16テストファイル、91テストが成功する。

## テストシナリオ

- 全自動テストを実行し、ページ分割、保存境界、入力整形、アクセシビリティの回帰がないことを確認する。
- A4縦とA3横を切り替え、履歴書プレビューのページ数とレイアウトを確認する。
- A3横でグレー背景がなく、A4縦では既存背景が維持されることを確認する。
- 一般応募と障害者雇用応募を切り替え、配慮事項の入力・出力境界を確認する。
- JSON保存・読込後に入力内容と用紙・書体設定が復元されることを確認する。
- デスクトップ幅と狭幅表示で、入力フォームとナビゲーションに欠けや重なりがないことを確認する。
- 文書内の相対リンク、マニュアル正本と公開版、全Specsの必須見出しが自動検査を通ることを確認する。

## ロールバック時の注記

- コンポーネント抽出とカスタムフックは相互依存するため、`App.tsx` だけを単独で旧版へ戻さない。
- ページビルダーを戻す場合は、`printPagination.ts` の定数化とテストも同じ時点へ戻す。
- A3背景だけを戻す場合は、`.resume-a3-page` の `--resume-header-bg` 上書きのみを削除する。
- 文書検査を戻す場合は `check:docs` と `check` の参照を同時に削除し、アプリ実行時の挙動には影響させない。
- JSONスキーマには変更がないため、このリファクタリングを戻しても既存の保存ファイル変換は不要。
