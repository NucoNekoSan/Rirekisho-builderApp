# REQUIREMENTS

## プロダクト目的

利用者本人が、自分のペースで履歴書を入力し、一般応募と障害者雇用応募のどちらにも使えるA4/A3応募書類PDFを安全に作成できるようにする。

## 利用者

- 主利用者: 就労移行支援事業所に通う、様々な障害のある利用者本人
- 補助者: 支援員。代行入力者ではなく、本人の入力・確認を補助する立場

## MVP成功条件

- A4縦またはA3横の履歴書PDFを表示・ダウンロードできる。
- 応募種別として `一般応募` / `障害者雇用` を選べる。
- 障害者雇用応募では、A4配慮事項シートを追加作成できる。
- 配慮事項シートの機微項目は本人が項目別ON/OFFで出力を選べる。
- JPG/JPEGの履歴書写真を取り込み、PDFへ反映できる。
- 入力データをJSONファイルとして保存・読込できる。
- サーバーへ個人情報を保存しない。

## Must

- React + TypeScript + Vite の静的SPA。
- Xserver通常レンタルサーバーへ `dist/` を配置して動作する。
- A4縦・A3横履歴書、A4配慮事項シートのPDF生成。
- 写真上限は単一設定値から参照する。
- ブラウザストレージに住所、電話、写真、障害情報、履歴書本文を保存しない。

## Won't in MVP

- 職務経歴書
- 添え状
- 支援員アカウントやレビューコメント
- サーバー保存、DB保存
- B4/B5等、A4縦・A3横以外の用紙バリエーション
