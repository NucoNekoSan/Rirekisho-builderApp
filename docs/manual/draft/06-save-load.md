# 第6章 入力データの保存・読込

## 6-1 なぜ保存が必要？

このツールは **サーバーには何も預けません**。
入力した内容は、明示的に有効化した場合だけ **この端末のブラウザ内** に自動保存できます。端末を移る場合やバックアップには **JSON ファイル** を使います。

> ★ **保存しないでブラウザを閉じると、入力した内容は消えます。** 途中で休むときも、必ず保存してから閉じます。

## 6-2 入力データを保存する

▶ 手順：

1. 画面左メニューの「保存・PDF」を選ぶ
2. **入力データ保存** カードを見つける
3. 写真も一緒に残したいなら「写真も入力データに含める」にチェック（個人情報なので注意）
4. **入力データを保存** ボタンを押す
5. パソコンの「ダウンロード」フォルダに `.json` 拡張子のファイルが入る

> 💡 ファイル名はわかりやすく **「日付＋氏名」** にリネームしておくと、後で見つけやすいです。
> 例：`2026-06-30_佐藤花子.json`

### 写真を含めるかどうかの判断

| シチュエーション | 含める？ |
|---|---|
| 自分のパソコンに保存（USB含む） | 含めてもOK |
| クラウドや事業所共有フォルダに置く | 慎重に。基本は含めない |
| メールで誰かに渡す | 含めない。写真は別途共有 |

> ⚠ JSON ファイル内では写真は **Base64 文字列** として保存されます。テキストエディタで開けば一応見えてしまうので、共有先を選んでください。

## 6-3 入力データを読み込む

別の日に続きから再開する手順。

▶ 手順：

1. 事業所から案内されたURLでツールを開く
2. 「保存・PDF」セクションへ移動
3. **入力データを読込** ボタンを押す
4. ファイル選択ダイアログで先ほどの `.json` を選ぶ
5. 入力欄に内容が戻る

> 💡 配慮事項シートを無効にして保存したJSONには、配慮事項の内容を含めません。

## 6-4 データ初期化（すべて消す）

別の人の履歴書を作りたいときや、デモデータを試したあとに使います。

▶ 手順：

1. 「保存・PDF」セクションの **データ初期化** カードを見つける
2. **入力をすべて消す** ボタンを押す
3. 確認メッセージが出るので **消去する** を押す

> ⚠ 初期化するまえに、必要なら入力データを **保存してから** 初期化してください。

## 6-5 事業所での運用ルール（例）

| 状況 | 推奨 |
|---|---|
| 入力途中のファイル | 事業所 PC の「マイドキュメント」配下に氏名フォルダを作って保存 |
| 完成 PDF | 同上＋応募先名のサブフォルダ |
| USB 持ち帰り | 写真は **含めない**。家でもう一度開けるようにテスト |
| 共有フォルダにアップ | 組織の情報管理ルールを確認する |
